# 右键菜单管理

从 v0.6.2 开始，侧边栏有「右键菜单管理」小组件，点击打开弹出的管理页面；归档设置里也有入口。

## 使用范围

- 页面顶部管理归序自己的 Windows 11 一级「复制文件路径」命令，支持添加、移除、重新注册修复。
- 「可调整」列出可为当前账户停用的第三方传统命令和上下文菜单组件，通常出现在「显示更多选项」。同一个软件在多个位置注册时分别列出；一个组件可能生成多个实际命令。
- 「全部项目」包括系统命令和已注册的 Windows 11 一级菜单组件。注册信息不等于每次右键都会显示；软件会根据选中的文件和自身设置决定是否显示。部分软件也在传统注册表中使用 ExplorerCommandHandler，页面将其列在传统注册区域，实际层级可能因 Windows 与软件实现而不同。
- 「归序停用」集中显示归序保留恢复记录的项目，可逐项恢复或点击「恢复归序停用的项目」。
- 可以按菜单/软件名称搜索，筛选文件、文件夹、磁盘、空白处和特定文件类型。每页最多显示 50 项。

归序保护常见 Windows 基础操作及可识别的 Microsoft/Windows 组件，不直接停用。其他软件的应用身份包菜单目前仅可查看，请从所属软件的设置启用或关闭；归序不会为了隐藏菜单卸载整个应用。此版本不枚举所有动态子命令、SendTo、New、新建文件模板，也不管理其他账户或 32 位外壳。

## 更改和恢复

传统静态命令通过当前账户 `Software/Classes` 中的 `LegacyDisable` 覆盖隐藏；上下文菜单组件通过该出现位置的 `shellex/ContextMenuHandlers` 默认 CLSID 加 `-` 前缀建立无效引用，阻止该处加载。只覆盖选中的上下文菜单注册，不使用全局 Shell Extensions Blocked，也不修改预览或缩略图注册。原软件的 HKLM 注册、命令、文件都保留。

归序在写覆盖前，将原值、原类型、注册指纹和已写值保存到 `HKCU/Software/TidyDrop/MenuOverrides`。恢复时只移除自己的标志或还原自己的覆盖，原值类型会保留。若所属软件更新了注册信息，或另一个工具修改了覆盖值，归序拒绝覆盖并保留恢复记录，提示在原软件中恢复。已被别的工具停用的项目只显示状态，不冒领恢复权。

恢复记录属于 Windows 当前账户，移动程序、换便携目录或重装归序后仍可读取。卸载归序不会自动恢复用户已经选择隐藏的第三方菜单；如需恢复，卸载前使用「恢复归序停用的项目」，或重新安装后恢复。软件已卸载导致原注册消失时，归序不会重新创建该软件的命令。

菜单开关完成后归序发送外壳关联刷新通知；已加载的扩展可能继续缓存。请先关闭菜单重新右键，再重开文件夹窗口；仍未生效时退出并重新登录 Windows。归序不强制结束或重启资源管理器。

## 验证

`tests/TidyDrop.MenuChecks` 只生成临时 HKCU 注册、菜单和材料，验证停用/恢复、原类型与其他值保留、重新创建管理器后的恢复记录、未知 ID 拒绝、软件更新/其他工具冲突保护和写入前中断恢复。配合原生检查程序可调用 Windows Shell 的 IContextMenu 验证测试命令确实隐藏和重新显示。不会修改真实第三方菜单，也不会执行它们的命令。
