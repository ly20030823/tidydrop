# 归序 v0.6.2

新增右键菜单管理页面，改进「复制文件路径」在资源管理器内的注册刷新。

- 侧边栏增加「右键菜单管理」小组件，点击弹出页面。
- 搜索和查看本机菜单，按出现位置、菜单层级筛选；支持逐项停用与恢复可调整的第三方传统菜单，以及恢复归序停用的项目。
- 更改只影响当前账户，保留原软件注册与恢复记录。Windows 系统项目和其他软件的应用身份包一级菜单仅供查看，需从所属软件设置调整。
- 归序菜单添加、移除、修复后通知 Windows 更新外壳缓存。新增「修复归序菜单」，重新注册并刷新。
- 改进资源管理器暂时无法提供文件属性时的状态查询，避免过早隐藏复制路径命令。

推荐下载 `TidyDrop-Setup-0.6.2-win-x64.exe`，也提供自带 .NET 的便携 ZIP。安装版可覆盖升级，材料、设置和记录保留。首次添加归序一级菜单仍使用个人开发签名，需要明确授权本机签名信任与管理员确认。

如果桌面有菜单、文件夹内没有，更新后点击「修复归序菜单」，再重开文件夹窗口；仍不显示时退出并重新登录 Windows。归序不会自动重启资源管理器。此问题已补充缓存刷新与状态查询处理，资源管理器实际显示仍需在你的电脑上确认。

检查覆盖真实 Windows Shell 的测试命令隐藏/恢复、恢复记录和冲突保护、原生复制路径及延后查询、界面联动、后台收纳、安装、升级和卸载。不会为测试停用真实第三方软件的菜单。
