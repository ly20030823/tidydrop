# 归序 v0.7.0

重新实现日常右键菜单管理，解决同名命令被混合、出现位置不清楚和缺少特殊菜单的问题。

- 按文件、文件夹、文件夹空白处、桌面空白处等位置浏览，保留按软件查找。
- 命令身份与显示名称分开，同名不同功能不会被一个开关误合并。
- 展开查看子菜单、来源、实际调整范围；选择文件/文件夹分析相关注册。
- 新增新建模板、发送到、打开方式的独立管理和恢复。
- 在独立进程识别动态标题与子命令，设超时；名称后台更新，不阻塞列表。
- 保留旧版恢复记录，保护软件更新和其他工具的改动。

普通菜单只调整当前账户；整机新建模板需要管理员确认，影响全部账户。系统基础组件、共享子命令和第三方一级菜单组件仍仅查看。注册状态不等于每次右键的实际显示状态。

提供 Windows 11 x64 安装包、便携版和 SHA-256 校验文件。已有设置、整理记录和归档材料保留。个人开发签名的信任方式见 [安装说明](../installation-and-release.md)。

验证包括真实 Windows Shell 中普通命令、私有子命令、新建模板的隐藏与恢复，恢复数据与类型保留，命令身份/位置筛选、界面桥接、独立运行、安装升级卸载，以及归序原生复制路径组件回归。
