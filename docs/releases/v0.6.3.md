# 归序 v0.6.3

整理右键菜单管理列表，并改进复制路径命令在资源管理器中的选中项处理。

- 菜单按软件和功能合并，优先展示友好名称，展开查看出现位置。增加「软件菜单」「系统与其他」和「只看可调整」，避免重复注册挤满页面。
- 按当前文件关联读取菜单；主开关批量调整当前筛选的位置，保留逐位置恢复记录，并报告部分失败。
- 复制路径命令支持资源管理器提前查询状态、通过选择对象或文件夹视图提供选中项；明确的空选择、虚拟项目不会改动剪贴板。

本机实际验证：旧资源管理器进程中仍不显示；重新加载资源管理器后，文件夹内的文件和文件夹都出现一级「复制文件路径」。因此更新后若桌面有、文件夹没有，请修复归序菜单，再重启资源管理器或退出并重新登录 Windows。归序不会自动重启资源管理器。

已验证原生路径复制及 Windows 注册后的 COM 调用、18 项菜单读取/更改/恢复检查、26 项收纳检查、界面分组与联动、静默桌面收纳、安装/升级/卸载及保留数据。

推荐下载 `TidyDrop-Setup-0.6.3-win-x64.exe`。提供自带 .NET 的便携 ZIP。仍使用个人开发签名；首次添加一级菜单需要本机信任授权和管理员确认。其他软件的应用身份包一级菜单目前仅可查看，请在所属软件中调整。
