# 归序 v0.7.1

修复打开或刷新右键菜单管理时，可能弹出旧版 Windows Media Player 首次设置窗口的问题。

- 取消为识别菜单名称而主动创建第三方 COM 组件。初始化组件本身也可能启动所属软件，即使没有执行菜单命令。
- 菜单名称改为读取现有注册、本地化资源和应用包清单；无法识别时保留软件名称和原始标识。
- 保留菜单分组、注册来源、开关和恢复记录。运行时生成的动态子命令不再主动查询。
- 旧的动态查询启动参数直接拒绝，避免再次激活组件。

无需设置或启用 Windows Media Player，也不修改播放器设置、默认关联、归档材料或用户清单。

提供 Windows 11 x64 安装包、便携版和 SHA-256 校验文件。个人开发签名的信任方式见 [安装说明](https://github.com/ly20030823/tidydrop/blob/main/docs/installation-and-release.md)。
