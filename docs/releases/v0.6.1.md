归序现在提供 Windows 11 x64 安装程序，可以在另一台电脑下载安装后直接使用。

## 下载与使用

- **推荐：`TidyDrop-Setup-0.6.1-win-x64.exe`**。中文安装向导，自带 .NET 9.0.20 运行环境；系统缺少 WebView2 时自动联网安装。
- `TidyDrop-0.6.1-win-x64-portable.zip`：自带 .NET 的便携版，解压整个目录到固定、可写的位置。系统需要已有 WebView2。
- `SHA256SUMS.txt`：以上文件的 SHA-256 校验值。

安装后首次打开归序，选择归档总文件夹。把文件或文件夹拖到桌面「归序」入口即可在后台收纳，双击入口查看归档空间。

## 本次变化

- 修复右键菜单安装的 `0x800B0109` 证书信任错误。需要的签名信任改为本机「受信任人」，由独立的管理员步骤处理；菜单仍注册给当前账户。
- 安装时可选创建桌面入口和添加一级「复制文件路径」菜单，也可以稍后从归序设置添加或移除。支持文件、文件夹和多选，每行一个完整路径，不带引号，复制时无需打开归序。
- 安装和卸载会等待归序关闭，不强制结束正在收纳材料的程序。覆盖升级保留设置和整理记录；卸载保留设置、记录及所有归档材料。
- 保留材料清单、按日期与类型浏览、左右滑动动画，以及文件夹整包收纳。

## 本地签名说明

此版本仍使用个人开发签名，Windows 可能显示未识别应用或 SmartScreen 提醒，请核对下载来源与校验值。

勾选右键菜单后，安装向导会说明并请求管理员确认，将公开代码签名证书加入 **本机 / 受信任人**。这份信任对所有账户生效，也适用于同一私钥签名的其他安装包；不加入根证书库，不随程序提供私钥。取消确认不影响归序主体的收纳功能。移除菜单或卸载时清理归序新增的信任，其他账户仍使用菜单时保留。

换电脑安装不会自动同步材料和设置；首次使用需选择新电脑的归档位置。详情见仓库中的 [安装与 Release 说明](https://github.com/ly20030823/tidydrop/blob/main/docs/installation-and-release.md)。
