# 归序 v0.9.0

归档空间新增删除功能，支持文件、整包文件夹和多选。

- 点击材料旁的「删除」，或勾选当前结果后点击「删除所选」。确认窗口显示材料名称、数量及文件夹内容提醒。
- 材料移入 Windows 回收站，无法回收时保留；不转为永久删除。
- 同步更新材料清单、日期与类型视图。整理记录保留，成功时标记「已移入回收站」。
- 如需恢复，在 Windows 回收站还原，再点击归序「刷新」。原来的「撤销」继续用于恢复收纳前的原位置。
- 新增 [开源收纳工具功能调研与后续计划](https://github.com/ly20030823/tidydrop/blob/main/docs/organizer-feature-research.md)：重复材料提醒、项目标签、轻量预览、可选目录监控和简单分类规则。这些借鉴功能尚未实现。

已有材料、设置、清单、整理记录及菜单管理保留。已验证真实回收与还原、单份与批量操作、取消，以及清单和记录保存失败、中断后的处理。

提供 Windows 11 x64 安装包、便携版和 SHA-256 校验文件。个人开发签名的信任方式见 [安装说明](https://github.com/ly20030823/tidydrop/blob/main/docs/installation-and-release.md)。
