# 归序 v0.8.0

右键菜单管理改为三层结构：**软件 → 菜单条目 → 出现位置**。

- 默认先显示 WPS、百度网盘等软件，展开后查看它们注册的菜单条目。
- 展开某个条目，再查看它在文件、文件夹、桌面等哪些位置出现，逐位置停用或恢复。
- 保留同名不同命令的独立身份；子菜单条目归在父菜单所属软件下，相同命令的不同位置合并查看。
- 搜索软件、条目或位置后，仍完整显示该条目的所有位置；只读项目明确标注。
- 保留新建模板、发送到、打开方式、对象分析和归序恢复记录。

继续使用被动名称读取，不主动加载第三方菜单组件。已有材料、清单、设置和恢复记录保留。

提供 Windows 11 x64 安装包、便携版和 SHA-256 校验文件。个人开发签名的信任方式见 [安装说明](https://github.com/ly20030823/tidydrop/blob/main/docs/installation-and-release.md)。
